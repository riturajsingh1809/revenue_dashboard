## 📌 Project Overview

This project is a Revenue Dashboard developed as part of a Data Analyst Internship. The dashboard analyzes revenue data, payment status, payment methods, courses, and city-wise performance to generate meaningful business insights.

The project demonstrates the complete data analysis workflow, including data cleaning, KPI calculation, visualization, and dashboard development.

---

## 🎯 Project Objectives

- Analyze revenue data
- Generate business insights
- Calculate Key Performance Indicators (KPIs)
- Visualize revenue trends
- Compare payment performance
- Create an interactive dashboard

---

## 📂 Dataset

*Dataset Name:* Sample_Dataset.xlsx

The dataset contains sample revenue transaction records with the following information:

- Date
- User ID
- Course
- Category
- Payment Method
- Payment Status
- Amount
- Discount
- Revenue
- City
